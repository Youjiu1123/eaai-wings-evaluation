# Reproducibility package for Figures 3–11
This package reproduces Figures 3–11 of the manuscript. Figures 1 and 2 are conceptual illustrations and are not included.
This package only contains plotting routines and frozen post-processed datasets. No aerodynamic simulation, candidate generation or model training code is provided.

## Environment
Python ≥ 3.9

pip install -r requirements.txt
