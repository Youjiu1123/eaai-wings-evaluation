Reproduction Package for Tables
This package reproduces the numerical results of Table 1–3 and Supplementary Tables S1–S7 in the manuscript submitted to Engineering Applications of Artificial Intelligence (EAAI).

Scope Statement
This release only includes evaluation scripts, fixed pre-trained model checkpoint, and experimental input conditions.
Training pipeline, aerodynamic solver, raw simulation codes and mesh files are NOT included.
This package cannot be used for retraining or generating new aerodynamic results.
